## 修复：窗口置顶功能

### 问题
- "窗口置顶"菜单项不生效
- 缺少状态反馈（置顶时无视觉提示）

### 修复内容
1. **main_window.py**:
   - `_show_context_menu`: 菜单文本根据状态动态变化
     - 未置顶时显示 "📌 窗口置顶"
     - 已置顶时显示 "🔓 取消置顶"
   - `_toggle_always_on_top`: 添加 `self.hide()` 解决 `setWindowFlags` 在已显示窗口上失效的问题
   - 版本号: v1.3.1.0 → v1.3.2.0

2. **version_info.py**: 版本号同步更新至 1.3.2.0

### 关键代码改动
```python
# 菜单文本动态化
is_on_top = self.cfg.get("always_on_top", False)
act_top = QAction("🔓 取消置顶" if is_on_top else "📌 窗口置顶", self)

# 置顶切换（修复失效问题）
def _toggle_always_on_top(self, checked: bool):
    self.cfg["always_on_top"] = checked
    flags = Qt.FramelessWindowHint
    if checked:
        flags |= Qt.WindowStaysOnTopHint
    self.hide()  # 关键：先隐藏
    self.setWindowFlags(flags)
    self.setAttribute(Qt.WA_TranslucentBackground, True)
    self.show()
    save_config(self.cfg)
```
